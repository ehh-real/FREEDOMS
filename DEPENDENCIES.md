# Dependensi

| Kebutuhan | Dependensi |
|---|---|
| Website produksi | Server hosting file statis; tidak ada paket pihak ketiga |
| Browser | Browser modern yang mendukung HTML dialog, CSS Grid, dan JavaScript ES2015+ |
| Preview opsi Python | Python 3, pustaka standar saja |
| Preview opsi Node | Node.js >=18, modul bawaan saja |
| Build | Tidak ada proses build |
| Database/API/env | Tidak digunakan |

Tidak ada package-lock.json karena tidak ada dependensi npm yang harus di-resolve.
